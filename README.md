# はたらくドロップ

はたらく乗り物（消防車が主役）を落として合体させる、ブラウザで遊べるパズルゲームです。
同じ乗り物どうしがぶつかると、ひとつ大きい乗り物になります。いちばん大きい「ちょうだいはしごしゃ」を目指しましょう。

- 遊ぶ: https://nyanta-kun.github.io/hataraku-drop/
- 操作: タップ（クリック）した位置に乗り物が落ちます
- 外部への通信はありません。ハイスコアと音の設定は端末内（localStorage）にだけ保存します
